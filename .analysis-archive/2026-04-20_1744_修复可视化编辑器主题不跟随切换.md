<analysis>
context:
  1. 可视化表格编辑器的 DOM 根节点不是 `#acu-visualizer-root`，而是 `#acu-visualizer-content`。证据：
     - `src/presentation/pages/visualizer.ts` 第92-129行创建的 content 里根元素是 `<div id="acu-visualizer-content" ...>`
     - grep 结果显示 visualizer 样式文件 `src/presentation/pages/visualizer-styles.ts` 大量选择器都基于 `#acu-visualizer-content`
  2. 主题系统在 `src/presentation/theme/theme-registry.ts` 第239-245行对 visualizer 的注入逻辑是：
     - 如果 `theme.visualizerVariables` 存在，就生成 `#acu-visualizer-root { ... }`
     这说明主题注入选择器压根写错了目标节点。漏洞明显得像是故意写给事故看的：样式注入到了一个实际不存在的根节点上，当然不会生效。
  3. `theme-types.ts` 中虽然注释写的是 `#acu-visualizer-root`，但实际代码和样式文件都围绕 `#acu-visualizer-content` 工作。这说明文档和实现已经脱节，属于一致性缺陷。
  4. grep 显示 `visualizer-styles.ts` 内还有大量 `var(--vis-...)` 形式的变量使用，以及部分固定作用域 `body.acu-theme-silk #acu-visualizer-content` 这类主题类选择器。说明 visualizer 本身是有独立变量体系的，但当前主题系统没有把变量注入到正确根节点。
  5. 当前 `theme.visualizerVariables` 默认大多为空对象；而且即便提供了，也因为注入到了错误选择器 `#acu-visualizer-root` 上，运行时完全吃不到。
  6. 由于 visualizer 窗口也是通过独立窗口系统挂载，不在 `#popup_acu` 内部，因此它不能依赖 popup 根变量继承，必须像 toast / confirm / window chrome 一样被单独注入到正确作用域。
  7. 这次问题的根因非常单一：**视觉编辑器主题变量的注入目标节点写错了**。如果不同时修类型注释与导出模板说明，后续主题作者还会继续被错误文档带偏。

needs:
  1. 让可视化表格编辑器的 UI 风格真正跟随当前主题切换。
  2. 把 visualizer 变量注入到实际存在的根节点 `#acu-visualizer-content`，而不是不存在的 `#acu-visualizer-root`。
  3. 同步修正文档/类型注释中的错误选择器，避免主题作者继续按错误目标写 CSS。
  4. 保持旧主题兼容：即使 `visualizerVariables` 为空，也要至少让基于核心变量的部分能正确吃到作用域变量。

key_challenges:
  1. 需要确认 visualizer 样式是否只依赖 `theme.visualizerVariables`，还是还依赖核心变量；如果两者都有，则需要把核心变量也注入到 visualizer 作用域。
  2. 不能只改注释不改运行时逻辑；否则 UI 仍然不会变。
  3. 不能只改运行时逻辑不改注释；否则主题作者以后还会继续对着错误选择器配置。
  4. visualizer 可能在主题切换前后动态创建，注入逻辑必须对后创建的节点同样生效。

confidence: HIGH
  - 根因已明确：选择器写错
  - 影响范围集中，运行时修复路径直接

approach:
  采用“修正 visualizer 注入目标 + 同步注释/模板说明”的方案：
  1. 修改 `theme-registry.ts` 中 visualizer 变量注入选择器，从 `#acu-visualizer-root` 改为 `#acu-visualizer-content`。
  2. 为了稳妥起见，如果 visualizer 样式还会用到核心变量，则同步把主题核心变量也注入到 `#acu-visualizer-content` 作用域，而不仅仅是 `visualizerVariables`。否则编辑器可能只拿到少量 `--acu-viz-*`，仍然无法完整跟随主题。
  3. 修改 `theme-types.ts` 中关于 visualizer 的注释，把错误的 `#acu-visualizer-root` 更正为真实根节点 `#acu-visualizer-content`。
  4. 若导出模板/提示中出现旧选择器，也一并更正，防止后续继续扩散错误。

  - 若 `visualizer-styles.ts` 中存在基于 `body.acu-theme-silk` 的特例样式，这些不会被本次直接破坏，但仍需保证根变量作用域正确
