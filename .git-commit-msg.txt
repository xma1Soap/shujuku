fix: 模型加载改用custom_url+custom_include_headers传参

标准SillyTavern后端处理Custom源:
- apiUrl = custom_url
- apiKey = readSecret(CUSTOM)  // 从secret store读，插件无法注入
- headers = mergeObjectWithYaml({}, custom_include_headers)
- 最终请求: { 'Authorization': 'Bearer ' + apiKey, ...headers }
- ...headers在后展开，覆盖前面的Authorization

所以通过custom_include_headers传Authorization可以绕过secret store
之前用reverse_proxy+proxy_password方案不适用标准SillyTavern后端
